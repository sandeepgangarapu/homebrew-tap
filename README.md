# Homebrew tap

Apps by Sandeep Gangarapu.

```sh
brew install --cask sandeepgangarapu/tap/mdown
```

| Cask | App |
| --- | --- |
| `mdown` | [MDown](https://mdown.sandeepgangarapu.com), the simplest and cleanest Markdown editor for Mac |

MDown updates itself after it's installed, so `brew upgrade` isn't needed for it.
